# @local/analyst

问数插件，只出现在「数据分析」预设里。它不保存数据源，也不保存页面。`localAnalyst` 用 isolate 留在预设内部。

问数先对当前知识库的页面、字段和字典。对不上时第一句说明答不了，只追问对应的表和字段，不用相近字段或日志里的人名代替，也不先给汇总表或图。当前知识库、已绑定的数据源和已选表写在每轮请求的运行时上下文里。这一段在进入模型前按当前选中的知识库重读，默认知识库同样生效，不经过工具调用。`analyst_execute_readonly` 只接受其中的数据源。字面值用这个知识库的原料校验，SQL 里的表必须落在该知识库为这个数据源选择的范围内，再调用 `localDatasource.runReadonly`。禁用表、禁用列和行数上限来自策略。预设里不提供列出或新增全部数据源的工具。用户说「确认口径」后，预设把刚才成功的 SQL 或确认的那句话经 `deposit` 回到 wiki 原料。这个方法不注册成模型工具。

运行测试：`node --test test/*.test.mjs`
