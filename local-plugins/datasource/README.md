# @local/datasource

数据源插件。拥有连接、加密凭据、结构剖析和只读 SQL。

向宿主提供 `localDatasource`。数据源上的 `scope.tables` 是默认采集范围。知识库未单独保存范围时使用它，知识库里的调整不写回这里。模型工具只有 `datasource_list` 和 `datasource_add`。`/datasource` 还接受 `update`、`remove`、`catalog` 与 `check`：更新时密码留空表示不改凭据，`catalog` 按已保存的 id 列出可勾选的库和表；还没有 id 时用与 `check` 相同的连接参数列出，这次不写连通状态。`check` 只做探测，也不改已保存的连通状态。按 id 读库或采集真正连上之后才更新连通状态。一次采集读出表注释、列、主键、索引和声明的外键，整表采样后写成一条 `db.table` 原料。两边样本都完整时，关联用不同值集合的精确包含率。样本只覆盖部分行时，标识列和证件号会拿另一张表的取值回全表做精确包含查询。采集是否完成记在知识库上。正文和证据用 `@local/contracts` 的同一份表文档。表总行数是全表行数，采样行数是实际读到的行。每列证据保留空值率、基数和区分度，这三项按采样行计算。行数或非空值不足 20 时不提取字典、值域和关联。时间列、创建人、更新人和乐观锁版本不进入值域或字典。证件类型仍可以成为字典。时间列不参与关联。MySQL 的大整数以字符串读取。问数执行由 analyst 调用 `runReadonly`，并带上策略里的禁用表和列。

密钥文件默认是 `~/.dsh-datasource/secret.key`（0600）。

运行测试：`node --test test/*.test.mjs`
